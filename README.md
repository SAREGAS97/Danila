# Danila
Проект по курсу «Основы синтаксиса языка программирования Python»: примеры базовых конструкций, работа с типами данных, условными операторами и циклами. В репозитории — упражнения и решения задач из курса.
Основные темы курса:
Переменные и типы данных
Условные операторы (if/elif/else)
Циклы (for, while)
Функции и область видимости
Работа со списками, словарями и кортежами
